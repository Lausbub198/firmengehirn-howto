# Firmengehirn zum Selberbauen · The company brain, built yourself

Begleitpaket zum Video von **Lokale KI mit Andreas Nürenberg**: ein eigenes ChatGPT für die Firma mit LibreChat,
Gemma 4 über Ollama, Diktat per Whisper und einem Wissensspeicher, der mit Fundstelle antwortet. Alles läuft auf
dem eigenen Rechner.

Companion package to the video by **Lokale KI mit Andreas Nürenberg**: your own company ChatGPT with LibreChat,
Gemma 4 via Ollama, dictation via Whisper and a knowledge store that answers with the source location. Everything
runs on your own machine.
